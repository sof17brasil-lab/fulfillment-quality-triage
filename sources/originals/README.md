# Saved copies of the sources

Save a PDF of each source here on the day you check it (in a browser: Print, then Save as PDF).
Name each file with its ID from SOURCES.md, for example `S01_q2_2026_prepared_remarks.pdf`.

Why: job postings get taken down and pages change. A saved copy is your proof of what the page said.

Keep these files on your computer. Do not publish them on the website or GitHub, since they are other people's documents.
